# Random-Generator
This script generates random things.

Supports Python versions 3.8+. If you encounter problems installing the libraries, download the .exe file.

Hosted on GitHub. You are free to modify this source.

## Usage
### Modes:
Number: Generates a number between Min and Max; can generate decimal numbers with N decimal places.

Triang: Generates a number between A and B with a peak at C. The number is more likely to fall closer to the peak.

Symbols: Generates a sequence of characters of length N; you can edit the alphabet.

Choice: Selects a random element from your list.

Shuffle: Shuffles your list.

Bits: Generates random bits of length N.

Settings: You can change the list syntax, choose whether to copy or save the result, and change the generator seed (if you expand the window downwards).
